# 📊 레짐 기반 퀀트 트레이딩 시스템 — 프로젝트 계획서

---

## 1. 프로젝트 개요

**핵심 가설**: 시장 레짐을 ML로 분류하고, 레짐별 전략 비중을 동적 조절하면 전통적 규칙 기반 레짐 분류보다 나은 리스크 조정 수익률을 달성할 수 있다.

**A/B 비교 구조**:
- **Model A (벤치마크)**: 기술지표 + 거시지표 기반 **규칙(Rule-Based)** 레짐 분류
- **Model B (ML 모델)**: 머신러닝 기반 레짐 분류
- 레짐 분류 방법만 다르고, **나머지 조건은 모두 동일하게 통제**

---

## 2. 전체 파이프라인

```
데이터 수집 → 피처 생성 → 레짐 분류 (A vs B) → 전략 비중 조절 → 백테스트 → 비교 분석
```

---

## 3. 데이터

- **가격 데이터**: yfinance (ETF 기반 유니버스)
- **거시경제 데이터**: FRED API (VIX, 금리, 스프레드 등)
- **피처**: 기술지표 (SMA, RSI, MACD, ATR 등) + 거시지표 (금리 스프레드, HY 스프레드 등)

---

## 4. 레짐 분류

### 레짐 정의
- 🟢 강세 / 🔴 약세 / 🟡 횡보 / ⚫ 위기

### Model A (벤치마크)
- SMA 크로스, VIX 임계값, 금리 곡선 등 **규칙 기반** 분류

### Model B (ML 모델)
- 학습 데이터: 사후적 라벨링 (수익률 + 변동성 기준)
- 모델: 트리 기반(XGBoost 등) 또는 시계열 모델(LSTM 등) — 추후 선정
- Walk-Forward Validation으로 미래 정보 차단

---

## 5. 퀀트 전략

- **추세 추종 전략** (Trend Following): 모멘텀 + 이평선 기반
- **역추세 전략** (Mean Reversion): 볼린저밴드 + RSI 기반
- **레짐별 비중 조절**: 레짐에 따라 두 전략 + 안전자산 비중을 동적 배분

---

## 6. 백테스트

### 통제 환경 (A/B 동일)
- 투자 유니버스, 초기 자본, 거래비용, 리밸런싱 주기, 포지션 사이징 모두 동일

### 성과 지표
- 수익성: CAGR, 총수익률
- 위험: MDD, 변동성
- 리스크 조정: Sharpe, Sortino, Calmar

---

## 7. 비교 분석 (핵심)

1. **전체 기간 성과 비교**: Model A vs B vs Buy & Hold
2. **위기 구간 심층 분석**: 코로나, 금리 인상기 등에서 레짐 감지 속도 비교
3. **레짐 전환 속도**: 실제 레짐 전환 대비 얼마나 빨리 감지했는지
4. **오판 분석**: 위기를 놓친 경우(손실) vs 과잉 반응(기회비용)

---

## 8. 대시보드

- Streamlit 기반
- 레짐 히스토리, 누적수익률 비교, 위기 구간 분석 시각화

---

## 9. 구현 순서

| Phase | 내용 |
|-------|------|
| 1 | 데이터 파이프라인 (수집 + 피처) |
| 2 | 레짐 분류 모델 (라벨링 + Model A + Model B) |
| 3 | 전략 구현 (추세추종 + 역추세 + 비중 조절) |
| 4 | 백테스트 엔진 |
| 5 | 성능 비교 및 분석 |
| 6 | 대시보드 |
